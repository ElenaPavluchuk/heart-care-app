# Heart Care Charity Landing Page

This is a responsive landing page for a fictional non-profit organization focused on heart health protection. The project serves as a hands-on practice for advanced CSS techniques, featuring a unique, self-developed design. It emphasizes modern CSS for creating a full-fledged UX/UI interface with minimal JavaScript usage.

## Overview

Key learning objectives:

- Working with fonts and color schemes for visual appeal
- Utilizing basic and advanced selectors
- Optimizing the CSS Box Model for efficient layouts
- Exploring positioning, Flexbox, and Grid for structural control
- Implementing transforms, transitions, and hover effects for interactivity
- Achieving full responsiveness across devices

## Features

- **Unique Design**: Custom UI/UX tailored for a charity theme, including a logo, subscription form, and informational popup
- **Responsive Layout**: Fully adaptive for mobile, tablet, and desktop using media queries and flexible units
- **CSS-Focused Interactivity**: Hover effects, transforms, and animations powered by CSS
- **Minimal JS**: Only a small script for handling popup functionality (e.g., open/close events)

## Technologies Used

- **HTML5**: For semantic structure.
- **CSS3**: Core focus, including:
  - Fonts and colors (custom variables for themes)
  - Selectors (basic, pseudo-classes, combinators)
  - Box Model optimization (margins, paddings, borders)
  - Layouts (Position, Flexbox, Grid)
  - Effects (Transforms, Transitions, Hover)
  - Responsiveness (Media queries, viewport units)
- **JavaScript**: Minimal usage for popup toggling
- No external frameworks or libraries (pure vanilla approach)

## Getting Started

### Prerequisites

- A modern web browser (e.g., Chrome, Firefox).
- Code editor like Visual Studio Code (recommended for Live Server extension).

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/ElenaPavluchuk/heart-care-app.git
   ```
2. Navigate to the project directory:
   ```
   cd heart-care-app
   ```

No additional dependencies are required since this is a static HTML/CSS/JS project.

## Usage

To run the project locally:

### Using VS Code Live Server (Recommended for Development)

1. Open the project in Visual Studio Code.
2. Install the Live Server extension if not already installed
3. Right-click on `index.html` and select "Open with Live Server".
4. The page will open in your default browser

### Option 2: Simple Browser Open

- Double-click `index.html` to open it directly in your browser. This works for basic viewing but lacks live reloading.
